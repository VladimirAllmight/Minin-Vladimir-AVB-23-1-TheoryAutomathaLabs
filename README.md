## 📸 GUI реализованного приложения

### 🔘 Выбор стиля реализации
Программа позволяет выбрать стиль реализации часов с будильником: **объектно-ориентированный** или **процедурный**.

![Выбор стиля](https://github.com/user-attachments/assets/52773f8f-2ada-49e3-9c54-070dff94ae33)

---

### 🧩 Все состояния GUI
- **Слева** — реализация с использованием процедурного подхода.
- **Справа** — реализация с использованием объектно-ориентированного подхода.
- **Снизу** — интерфейс переключения между реализациями и настройки будильника.

![Все состояния](https://github.com/user-attachments/assets/21a181b2-d3a3-46c4-bb5f-f5f7afadd375)

---

### 🔍 GUI программы подробнее

Интерфейс поддерживает установку времени, настройку будильника, визуальную индикацию состояний и переходов автомата.
