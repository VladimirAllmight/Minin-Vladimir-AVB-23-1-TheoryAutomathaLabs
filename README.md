# Minin-Vladimir-AVB-23-1-TheoryAutomathaLabs

# 💡 Лабораторные работы по теме "Автоматы и регулярные выражения"

Данный репозиторий содержит набор лабораторных работ, посвящённых разработке и анализу конечных автоматов, регулярных выражений, работе с Docker и системами мониторинга. Каждая лабораторная работа размещена в отдельной ветке:

- `Laboratory_Work_1`
- `Laboratory_Work_2`
- `Laboratory_Work_3`
- `Laboratory_Work_4`

---

## 🧭 Навигация по лабораторным работам

### 🔹 Лабораторная работа №1 — Электронные часы с будильником (конечный автомат)

**Цель:**  
Построение конечного автомата для моделирования поведения электронных часов с будильником, реализация программного прототипа с графическим интерфейсом.

**Задания:**
1. Построить конечный автомат (табличная и графовая формы).
2. Реализовать часы с будильником двумя подходами: процедурным и объектно-ориентированным.
3. Создать GUI-интерфейс для управления часами.
4. Описать результаты работы.

**Ветка:** `Laboratory_Work_1`

---

### 🔹 Лабораторная работа №2 — Упаковка автомата в Docker

**Цель:**  
Научиться создавать и использовать Docker-образы.

**Задания:**
1. Написать `Dockerfile` для программы автомата из ЛР1.
2. Собрать и запустить контейнер.
3. Опубликовать образ в Docker Hub.
4. Проверить запуск на другом устройстве.

**Ветка:** `Laboratory_Work_2`

---

### 🔹 Лабораторная работа №3 — Мониторинг автомата через Grafana

**Цель:**  
Настроить мониторинг работы автомата через систему визуализации.

**Задания:**
1. Добавить логирование переходов автомата в PostgreSQL.
2. Развернуть Grafana и подключить базу данных.
3. Создать Grafana Dashboard (дашборд) с визуализацией состояний и переходов.
4. Проанализировать поведение автомата по графикам.

**Ветка:** `Laboratory_Work_3`

---

### 🔹 Лабораторная работа №4 — Регулярные выражения

**Цель:**  
Разработка и использование регулярных выражений для различных формальных языков.

**Задания:**
- Написание регулярных выражений для описания:
  - строк с обязательными символами;
  - ограничений на позиции символов;
  - сложных условий (кратность, парность, исключения);
  - телефонных номеров различных форматов;
  - описаний заработной платы в объявлениях.
- Программная реализация распознавания регулярных выражений.
- Проверка введённых пользователем символов.

**Ветка:** `Laboratory_Work_4`
