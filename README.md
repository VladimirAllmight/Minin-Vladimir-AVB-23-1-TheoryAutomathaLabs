## 🌐 Веб-приложение и контейнеризация (ЛР №2)

**Выполнил:** Минин Владимир, группа **АВБ-23-1**

В целях повышения удобства и эффективности использования программного продукта из лабораторной работы №1 было принято решение реализовать **веб-интерфейс** вместо десктоп-приложения.

### 📦 Причины перехода на веб-приложение при контейнеризации:

- **Портативность:** веб-приложение легко разворачивается в любом окружении без зависимости от графической оболочки.
- **Доступность:** интерфейс доступен через браузер с любого устройства в сети.
- **Инфраструктурная совместимость:** контейнеры Docker идеально сочетаются с веб-приложениями при использовании систем CI/CD и облачных решений.
- **Масштабируемость:** проще управлять несколькими экземплярами приложения (например, для разных пользователей) при помощи Docker и Docker Compose.
- **Изоляция:** вся среда выполнения упакована в контейнер, что исключает проблемы зависимости на стороне пользователя.
