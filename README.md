### 💻 Часть 4.2 — Реализация распознавания строк по регулярным выражениям

#### Даны регулярные выражения:

1. `(*)01*`  
2. `(0+1)01`  
3. `00(0+1)*`

#### Требуется:

- Реализовать **графическое приложение**, которое проверяет введённую строку на соответствие указанным регулярным выражениям.
- Обеспечить **валидацию ввода**, чтобы вводились только допустимые символы алфавита (`0`, `1`).
- Отображать результат: соответствует строка выражению или нет.

---

### 🛠️ Используемые технологии:

- Язык: **Java**
- Интерфейс: **Консольное приложение**
- Обработка регулярных выражений: **java.util.regex**
